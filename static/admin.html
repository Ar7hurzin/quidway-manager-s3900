COMO FUNCIONA

O login é sempre pelo SSO do provedor (com verificação em duas etapas); nenhuma senha é guardada aqui. Esta lista só define quem pode entrar. Todos têm o mesmo acesso ao painel; somente você ({{ user }}) administra esta lista. Remover alguém encerra o acesso imediatamente.

Com Google, um domínio inteiro (ex. @ufu.br) só libera contas do Google Workspace daquela organização. Contas Gmail pessoais precisam ser adicionadas individualmente. Confirme que cada pessoa tem a verificação em duas etapas ativada.
